Descargar los dos archivos HTML y abrirlo en un navegador (preferentemente Google Chrome).
Para el archivo 'mapa_emergencias_tacna_avanzado', use las distintas capas que se encuentran en la parte superior derecha para cambiar el tipo de visualización.
Para el archivo 'dashboard_emergencias_tacna_avanzado', use las distintas pestañas de tipo que se encuentran al medio y los filtros que se encuentran en la parte superior derecha para cambiar el tipo de visualización.
